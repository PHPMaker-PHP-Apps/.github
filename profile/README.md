# PHPMaker - PHP pages from a database you own

PHP pages should come from one named builder on a database you own. Mixed pasted scripts wait off the live project.

## Session Card

| Slice | What you do in PHPMaker | What remains |
|-------|-------------------------|--------------|
| Arrival | Open PHPMaker on a database you own and name the builder desk | A titled PHP project |
| Focus | Keep database pages on one PHPMaker web project | A short page list |
| Check | Read the pages before you generate PHP on data you own | A confirmed builder desk |
| Handoff | Leave PHPMaker PHP apps on that project | A note for the next visit |

## How PHPMaker Sits

PHPMaker does not replace the database you already own. It sits beside that engine as a named builder desk for PHPMaker PHP apps and PHPMaker database pages on a web project you keep.

## Traffic Light

| Signal | On the PHPMaker builder desk | What you do |
|--------|------------------------------|-------------|
| Green | Named PHP project, pages on your DB | Continue the same builder desk |
| Amber | Pages from two databases mixed | Split the set before a large change |
| Red | No title, mixed scripts everywhere | Stop and name the PHP project first |
| Clear | Handoff written, page list short | Close PHPMaker and leave the desk |

![PHPMaker](https://phpmaker.dev/docs/images/darkmodesm.png)

## Open Order

1. Open the last PHPMaker session on a database you own, not a new empty builder.
2. Read the database pages and the last handoff.
3. Finish one visible page inside PHPMaker PHP apps.
4. Write what changed on your own database, then close with fewer loose scripts than you found.
5. If the builder desk feels crowded, drop anything that belongs to a different PHPMaker job.

## After a Week

A week in PHPMaker is not more live pages. It is the same builder desk, a shorter PHPMaker database pages list, and a note that still makes sense on Monday. Leave PHPMaker with a quieter web project than the one you opened.

## Sign-off

- [ ] The PHPMaker project name is short enough to scan
- [ ] Only the database you own is on the builder desk
- [ ] A second person can read the last page note
- [ ] The last PHPMaker session still opens after a restart
- [ ] Finished pages are off the live set
- [ ] PHPMaker PHP apps still match the web project

## Field Note

PHPMaker is easier to trust when the builder desk stays smaller than the script folder it came from. Name the PHP project, keep PHPMaker database pages on a database you own, finish one visible page, and write what changed.

The same loop fits a shop file or a local PHP app you keep. Open the last PHPMaker builder desk and continue.
